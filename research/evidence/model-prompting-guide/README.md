# model-prompting-guide evidence — 공식 프롬프팅 문서 원문 스냅샷

Anthropic·OpenAI **공식 문서의 2026-07-24 snapshot**이다. [조사 synthesis](../../model-prompting-guide.md)의 결론을 다른 관점에서 재검토할 수 있도록 기본 읽기 경로 밖에 보존한다. 현재 제품 정보로 간주하거나 상시 agent context에 넣지 않는다.

규칙:

- 각 파일 상단 frontmatter(`source` / `fetched` / `note`)를 유지한다.
- 본문을 편집·요약·번역하지 않는다. 원문이 바뀌면 이 snapshot을 덮어쓰지 않고 별도 확인일의 evidence를 추가한다.
- OpenAI 스냅샷은 raw HTML→Markdown 변환본이다. UI 크롬은 제거했고, 다국어 코드탭은 기본 표시 탭 하나만 남는다(동일 예시의 언어판 차이일 뿐 내용 손실 없음).
- 라이선스나 공개 범위가 달라지면 전체 본문 대신 허용된 최소 인용과 원문 locator·확인일·무결성 식별자만 유지한다. 스킬과 프로토콜에는 원문 표현이 아니라 채택한 사상과 사실만 반영한다.
