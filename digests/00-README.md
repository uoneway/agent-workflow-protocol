# digests — 진행 중 검토의 입력

외부 조사(업스트림 스킬 레포·블로그·공식 문서)를 사용자 검토용으로 압축한 **packet**. 기준 문서도 영구 아카이브도 아니다.

수명은 하나의 규칙으로 정해진다. **결론을 권위 문서에 반영하면 삭제한다.** 채택분은 `AGENT_WORKFLOW_PROTOCOL.md`의 변경 이력에, 스킬 설계 판단은 `skill-rationales/`에, 소스별 흡수·기각 기록은 `upstream-sources.md`에 남긴다. 기각한 것도 남긴다 — 다음 스카우트가 같은 아이디어를 다시 올리지 않도록.

`upstream-scout`가 만드는 다이제스트가 기본 경로이고, 그 스킬의 순서는 변화 감지 → 필요할 때만 다이제스트 → 사용자 리뷰 → 결론 반영 → 삭제다.

## 현재 남아 있는 것

둘 다 `setup-workflow`의 영어 실행본 저작에 쓰인다. **그 승격이 끝나는 시점이 두 문서의 삭제 시점이다.**

| 파일 | 남아 있는 이유 |
| --- | --- |
| `2026-07-18-setup-transplant-survey.md` | 이식 메커니즘 서베이. 채택 패턴 8종은 초안에 반영됐고 소스별 흡수 기록은 `upstream-sources.md`에 있으나, 실행본을 쓸 때 "왜 이 구조인가"의 근거로 필요하다 |
| `2026-07-24-model-prompting-guide.md` | 모델별 프롬프팅 지도. 원문 스냅샷은 [`references/prompting/`](../references/prompting/)에 있고 이 문서가 그 지도다. **결론(절차 열거 대신 목표·제약·경계)은 2026-08-03에 [`skills/README.md`](../skills/README.md)로 승격**됐으므로, 남은 값은 실행본 저작 중 세부 지침을 찾아갈 때의 색인뿐이다 |

두 번째 문서는 업스트림 다이제스트와 성격이 다르다 — 만료 시점이 "결론 반영"이 아니라 모델 세대 교체다. 그래도 여기 두는 이유는 스냅샷과 함께 정리되어야 하기 때문이며, 세대가 바뀌면 갱신이 아니라 재조사로 대체한다.
