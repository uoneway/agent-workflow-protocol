# kickoff — 폐기된 스킬의 결정 기록

> **상태:** P-0022에서 폐기됨. 실행 스킬은 삭제됐다.

P-0002에서 작업 시작 전이를 분리했고, P-0014·P-0015에서 main 전용 `PROJECT_STATE`·`BACKLOG`, workstream 접합부, branch와 worktree 생성을 하나의 의식으로 묶었다. 당시에는 여러 스킬과 격리 환경이 상태를 추론하지 않도록 문서 접합면이 필요했다.

P-0020~P-0022는 현재 상태를 git·worktree·PR·session에서 읽고, 작업 계약을 맥락 이동에만 쓰도록 바꿨다. 수기 중앙 상태표가 없어지자 별도 kickoff 전이도 지킬 불변식이 사라졌다. branch·worktree·PR 준비는 레포와 실행 환경 정책에 따라 Act가 내부에서 수행한다.

폐기는 승인 경계를 없애지 않는다. `align`은 사용자가 시작·보류·중단 중 출구를 고르기 전 실행하지 않는다.
