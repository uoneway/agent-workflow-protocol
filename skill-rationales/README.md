# Skill Rationales — 한국어 의사결정 기록

이 폴더는 확정 스킬을 한국어로 검토하고 업그레이드하기 위한 기록이다. 영어 실행본 `skills/<name>/SKILL.md`가 agent의 **실행 기준**이고, 이 폴더는 그 실행본의 번역본·병행 명세·동기화 대상이 아니다.

각 기록은 스킬이 왜 존재하는지, 어떤 선택과 경계를 지키는지, 업스트림에서 무엇을 흡수하거나 기각했는지를 한국어로 보존한다. 초기 기록에는 승격 전 검토 초안도 함께 남아 있다. 그 안의 `[검토점]`·출처 태그는 당시의 검토 흔적일 뿐, 현재 열린 작업을 뜻하지 않는다.

## 업그레이드 규칙

스킬을 바꿀 때는 먼저 이 기록과 현재 영어 실행본을 함께 읽는다. 한국어로 변경 이유·대안·지켜야 할 경계를 합의하고 이 기록에 남긴 뒤, 그 결정을 반영해 영어 실행본을 다시 쓴다. 문장별 번역이나 두 파일의 기계적 일치가 목표가 아니다.

실행 행동이 바뀌면 `skill-rationales/<name>.md`와 `skills/<name>/SKILL.md`를 같은 변경에서 갱신한다. 실행과 무관한 조사 근거는 `upstream-sources.md`에, 현재 사용자가 읽는 설치·운영 안내는 루트 `README.md`에 둔다.
